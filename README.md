# Custom-Dev-Board
A custom dev board designed by me to allow me to create intricate projects

A minimal, high-performance prototyping board based on the Raspberry Pi RP2040.

Core Specs
MCU: Dual ARM Cortex-M0+ (133 MHz, 264 KB SRAM).

Storage: 2 MB QSPI Flash.

I/O: 20-pin breakout (GPIO, ADC, UART, SPI, I2C).

Clock: 12 MHz Crystal.

Power: USB-C (5V) to 3.3V LDO.


## How to Use:
Honestly idk, however you want, its a cheaper version of an esp-32, meant for small projects, its meant to be disposable in the sense of messing it up before a 100 dollar chip.

## Why I made this:

I made this because i wanted to test my skills, and allow me to easily create more intricate projects with ease. It is also a good starter project to learn the intricacies of PCB design.
